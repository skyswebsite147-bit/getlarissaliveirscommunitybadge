# Larissa Liveira Community Badge

A fan community website for Larissa Liveira where supporters can browse exclusive badge tiers, select a payment method, and connect with management.

## Features

- **5 Badge Tiers** — Diamond, Royal, Legacy, Supreme, and Immortal (Limited), each with escalating perks and pricing
- **Animated Concert Background** — The artist photo pulsates and sweeps with coloured stage-light overlays and spotlight animations for a live-concert atmosphere
- **Payment Method Selection** — Clicking any payment method (Cash App, PayPal, Apple Pay, Chime, Venmo, Gift Cards, Bitcoin) auto-opens a pre-filled email to management
- **Live USA Clock** — Real-time Eastern Standard Time shown in the top-right corner
- **Spotify Player** — Embedded mini-player for Larissa's latest single
- **Customer Support** — Email address displayed with one-click copy and direct mailto link

## Tech Stack

| Layer | Technology |
|-------|------------|
| Framework | TanStack Start |
| Frontend | React 19, TanStack Router v1 |
| Build | Vite 7 |
| Styling | Tailwind CSS 4 + custom CSS animations |
| Deployment | Netlify |

## Local Development

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Environment Variables

No environment variables are required for this project.
